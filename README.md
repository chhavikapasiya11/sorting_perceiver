🔍 Sorting Perceiver – Interactive Sorting Visualizer
Sorting Perceiver is a dynamic and interactive web-based sorting visualizer built to help users understand how various sorting algorithms work. With real-time animations and adjustable speeds, it's an educational tool for students, developers, and anyone curious about the inner workings of sorting techniques.

🎯 Key Features
🔢 Visualizes popular sorting algorithms:

Bubble Sort

Selection Sort

Insertion Sort

Merge Sort

Quick Sort

🎮 Interactive Controls:

Adjust speed and array size

Shuffle array

Pause and reset animations

🌈 Color-coded animations for better understanding
📱 Responsive Design – works on all devices
🎓 Perfect for learning and teaching sorting algorithms

🛠️ Tech Stack
HTML – For the structure of the visualizer

CSS – For styling the bars and layout

Vanilla JS – For sorting logic, DOM manipulation, and animations

(No frameworks or libraries used – built entirely with Vanilla JS)
